# TPC5

Pretende-se desenvolver uma app para gerir alunos, implementando dois serviços recorrendo ao express - `API de dados` e `front-end`


## Resultados
O código da solução pode ser encontrado em:  
[API de dados](https://github.com/joaoR21/EngWeb2025/blob/main/TPC5/API-dados) - aplicação em nodejs que recebe pedidos REST, interage com o `mongoDB` para obter os dados e responde em .json  
[front-end](https://github.com/joaoR21/EngWeb2025/blob/main/TPC5/front-end) - aplicação em nodejs que responde com uma interface web (templates .pug) a pedidos do utilizador (sempre que precisar de dados pede-os à API de dados).
